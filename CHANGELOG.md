
# Changelog

Historial de versiones de TOCA.

## [1.0.0] - En desarrollo

### Added

- Sistema de acceso al servicio mediante NFC.
- Página web individual para cada negocio.
- Identificación de negocios mediante slug.
- Enlace directo a Google Reviews.
- Sistema de gestión de negocios mediante estructura de datos.
- Identificador interno para cada negocio.
- Página 404 para negocios no registrados.
- Despliegue del proyecto mediante Vercel.
- Control de versiones mediante Git y GitHub.

### Technical

- Next.js con App Router.
- Rutas dinámicas mediante `[slug]`.
- Separación entre los datos de los negocios y la lógica de búsqueda.
- Sistema de búsqueda de negocios mediante `getBusinessBySlug()`.
